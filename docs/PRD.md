# PRD — 微信 AI 使用技巧整理站

> Stage 02 交付物。版本 v0.9 draft（待 Stage 02 验收后升 v1.0）。

## 1. 产品愿景
建立一个公网可访问、可搜索、有标签索引、可生成 Cheat Sheet 的微信 AI 技巧站点；从飞书导入、CloudBase 托管、MCP 暴露能力给外部 Agent。

## 2. 功能需求（FR）

### FR-1 内容管理
- FR-1.1 从飞书知识库 / 多维表格导入文章（含 Markdown 正文 + 图片附件）
- FR-1.2 一次性全量导入 + 增量同步命令
- FR-1.3 截图存储到 CloudBase 存储，文章仅保存引用 URL
- FR-1.4 文章支持撤回 / 删除（软删，保留 30 天回收站）

### FR-2 阅读与浏览
- FR-2.1 文章详情页（Markdown 渲染 + 图片懒加载）
- FR-2.2 文章列表页（按更新时间倒序）
- FR-2.3 Tag 列表页（点击 tag 过滤文章）
- FR-2.4 首页：精选 5 篇 + 最新 10 篇 + 热门 tag 云

### FR-3 搜索
- FR-3.1 顶栏搜索框；输入后 300ms debounce 触发查询
- FR-3.2 全文搜索覆盖：标题、正文、tag、截图 OCR（v1.1 可选）
- FR-3.3 结果按相关度排序，支持分页（每页 20）

### FR-4 标签系统
- FR-4.1 作者后台：tag CRUD
- FR-4.2 合并 tag（X、Y → Z'）：批量更新 ArticleTag 表
- FR-4.3 重命名 tag：保留别名映射，避免外链失效
- FR-4.4 Tag 频率云视图

### FR-5 Cheat Sheet 生成
- FR-5.1 PDF：选文章 → 渲染 → A4 → 下载
- FR-5.2 PNG 图卡片：1080×1440，含站点水印 + 文章标题 + 摘要 + 关键步骤
- FR-5.3 生成时间 < 10 秒

### FR-6 MCP 接入
- FR-6.1 `mcp.search_articles(query, limit, tags[])` → Top N 摘要 + URL
- FR-6.2 `mcp.get_article(id)` → 完整 Markdown + 截图 URL
- FR-6.3 `mcp.list_tags(prefix)` → 标签清单
- FR-6.4 不暴露写入接口；只读

### FR-7 部署与运维
- FR-7.1 公网域名（待定：CloudBase 默认域名 / 自定义）
- FR-7.2 备份：每周数据库导出 + 存储增量备份
- FR-7.3 监控：5xx 告警、函数冷启动耗时告警

## 3. 非功能需求（NFR）

| 项 | 要求 |
|---|---|
| 性能 | 列表页 P95 < 500ms；搜索 P95 < 300ms；Cheat Sheet P95 < 10s |
| 可用性 | 月度 99.5%；备份恢复 RTO < 4h |
| 安全 | 所有写接口仅本地/IP 白名单；MCP 仅返回公开文章；截图打码 SOP |
| 容量 | 数据库 ≤ 1GB；存储 ≤ 10GB；月函数调用 ≤ 100 万 |
| 隐私 | 截图含敏感信息强制打码；定期审计 |
| 合规 | 微信产品截图按官方使用规范；标注来源链接 |
| 预算 | 完全运行在 CloudBase 免费层内（**待核实** U1） |
| 可访问性 | 文字对比度 ≥ 4.5；图片 alt；键盘可达 |
| 国际化 | v1.0 仅中文 |
| 浏览器 | Chrome / Edge / Safari / Firefox 最新两个大版本 |

## 4. 范围控制
- 不做：登录、评论、点赞、社区、自动抓取、付费
- 延后：暗色模式、AI 自动建议 tag、统计、RSS
