# Problem Statement — 微信 AI 使用技巧整理站

> Stage 01 交付物。agentic-web-dev 技能 / 2026-09-19

## 当前问题
- 微信 AI（微信支付 AI 专属卡 / WeChat AI / 公众号 AI / 小程序 AI 等）能力众多，零散分布在各路文章、笔记、群聊和文档中。
- 用户已积累大量「技巧 + 截图」在飞书知识库 / 多维表格，但缺少一个**对外可检索、有标签索引、能产出 Cheat Sheet**的载体。
- 当前解决方案是手动翻飞书 / 重发群聊 / 截图复用，效率低、易丢上下文。

## 目标
建立一个**公网可访问**的 Web 站点，作为「微信 AI 使用技巧」的**单一事实来源（Single Source of Truth）**：
- 文章（含截图）可搜索、可标签、可关联
- 自动按 Tag 重建索引视图
- 一键生成可分享的 Cheat Sheet（PDF + 图卡片）
- 通过 MCP 接入云服务（CloudBase），让站点能力可被外部 Agent 调用

## 价值主张
- **对读者**：比零散笔记更易找、能打印带走
- **对作者**（用户本人）：导入一次，多端复用；Cheat Sheet 自动生成减少重复劳动
- **对生态**：MCP 接入使站点具备「被 Agent 检索」的能力，进入 AI 工具链

## 非目标（明确不做）
- ❌ 多用户登录 / 权限系统（单人维护）
- ❌ 评论 / 点赞 / 社交（公网访问但非社区）
- ❌ 实时协作编辑（导入是单向流程）
- ❌ 自动抓取公众号（合规风险）
