# COST-REGISTER — 微信 AI 使用技巧整理站

> Stage 04a 交付物。成本账目与监控。

## 1. 当前套餐
- **CloudBase FREE**：¥0/月
- 资源池：3,000 点/月
- 单免费环境，6 个月到期可续

## 2. 成本预估（MVP 量级）

### 2.1 估算假设
- 文章数：50 篇首发 → 半年增长到 200 篇
- 月活读者：~500 次浏览
- 月活 Agent：~50 次 MCP 调用
- 月活作者：~4 次导入

### 2.2 各组件用量估算

| 组件 | 估算 | 资源点估算 |
|---|---|---|
| 静态托管 | 1 个 Next.js 构建产物 + 50 张首屏图 | 包含在 1GB 免费 |
| CDN 回源 | 500 浏览 × ~500KB = 250 MB | ~50 点 |
| 数据库计算 | 50 + 500 查询 = 550 QPS 时 | ~30 CU/月 = ~600 点 |
| 数据库容量 | 50 文章 × ~5KB + 50 截图元数据 = 300KB | 可忽略 |
| 存储 | 50 截图 × 200KB = 10 MB | ~10 点 |
| 函数调用 | 4 导入 + 500 浏览 × 后端 SSR = 504 次 | ~50 点 |
| 函数计算 | 504 × 200ms × 256MB = 25 GBs | ~25 点 |
| 外网出流量 | 函数到外部 API ~10 MB | ~5 点 |
| MCP 调用 | 50 次 × 300ms = 15 GBs | ~15 点 |
| 备份 | 周备 4 次 × 5 MB 流出 | ~4 点 |

**月总用量 ~ 750-900 点**（远低于 3,000 点免费池）

### 2.3 月成本预测

| 套餐 | 月费 | 适用 |
|---|---|---|
| FREE | ¥0 | 当前预测用量 ✅ |
| FREE + 按量 | < ¥5（预留 buffer） | 若某月用量超过 3000 点 |
| PERSONAL | ¥19.9 | 若需要固定出口 IP 或更紧 SLA |
| STANDARD | $69 ≈ ¥500 | 不考虑 |

## 3. 升级阈值与告警

| 阈值 | 触发动作 |
|---|---|
| 月用量 > 2500 点（83%）| 告警；评估下月是否升级 |
| 月用量 > 3000 点 | 启用按量付费；当日费用 < ¥10 即可接受 |
| 单日费用 > ¥5 | 告警；可能是异常流量或函数死循环 |
| 单月费用 > ¥30 | 考虑升 PERSONAL |

## 4. 监控接入

- CloudBase 控制台自带用量监控
- 设置余额 < 10% 告警（FREE 层无余额概念，但按量付费开启后生效）
- 作者每周查一次用量面板

## 5. 优化机会

| 机会 | 节省 |
|---|---|
| 静态文章页全部 ISR 缓存 5 分钟 | 函数调用 -50% |
| 搜索加 CloudBase API 网关缓存 | 函数调用 -30% |
| 截图走 CloudBase 图片处理（自动 WebP）| CDN 回源 -40% |
| 数据库 query 加 explain + index | CU 消耗 -20% |
