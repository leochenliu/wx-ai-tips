# Acceptance Criteria — 微信 AI 使用技巧整理站（v1.0）

> Stage 02 交付物。可勾选的发布门槛清单。

## 发布门槛（Gate Criteria）

### G1 — 内容
- [ ] 至少 20 篇首发文章已导入并可访问
- [ ] 每篇文章至少 1 张截图且能正常加载
- [ ] 全部截图不含 API Key / 订单号 / 手机号等敏感信息（人工抽查 ≥ 20 篇）

### G2 — 功能
- [ ] US-1 导入全量 / 增量两条命令均可成功
- [ ] US-2 详情页、列表页、tag 页全部可访问且 < 500ms
- [ ] US-3 搜索覆盖标题 + 正文 + tag，且 P95 < 300ms
- [ ] US-4 tag CRUD / 合并 / 重命名 三个后台动作全部可用
- [ ] US-5 PDF + PNG 两种 Cheat Sheet 均能在 10s 内产出
- [ ] US-6 MCP 三个接口在 MCP Inspector 中测试通过
- [ ] US-7 周备脚本部署并跑通一次

### G3 — 性能
- [ ] 列表页 P95 < 500ms
- [ ] 搜索 P95 < 300ms
- [ ] Cheat Sheet P95 < 10s
- [ ] 首屏 LCP < 2.5s（4G 网络模拟）

### G4 — 安全
- [ ] 写接口仅本地或 IP 白名单可达
- [ ] MCP 仅暴露只读接口
- [ ] 截图打码 SOP 文档化，作者已跑通
- [ ] 数据库连接字符串不在前端 bundle 中

### G5 — 备份
- [ ] 周备 cron 已配置
- [ ] 最近一次备份 < 7 天
- [ ] 备份恢复演练成功一次（恢复到本地 Postgres）

### G6 — 文档
- [ ] README 包含启动 / 部署 / 备份 / 排错
- [ ] INFRASTRUCTURE-PLAN.md 包含免费额度核验日期
- [ ] COST-REGISTER.md 已建账目
- [ ] VENDOR-LOCK-IN-REVIEW.md 已记录锁定风险

### G7 — 监控
- [ ] 5xx 告警（邮箱或微信）
- [ ] 数据库 / 存储容量阈值告警（> 80%）
- [ ] MCP 调用失败率告警（> 5%）

## 不达标时的降级路径
- 若 G3 性能不达标：升级到 Meilisearch + Cloudflare CDN
- 若 G4 安全不达标：推迟发布，先补护栏
- 若 G5 备份不达标：暂用手动导出，必须在两周内补自动化
