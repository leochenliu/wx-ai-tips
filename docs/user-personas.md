# User Personas — 微信 AI 使用技巧整理站

> Stage 01 交付物

## P1 — 内容维护者（作者 = 你）
- **角色**：站点唯一编辑，整理微信 AI 技巧的人
- **场景**：从飞书知识库 / 多维表格导入文章；打标；更新 Cheat Sheet；偶尔修正导入遗漏
- **工具偏好**：本地 Markdown + CloudBase 控制台 + 飞书后台
- **痛点**：手动整理 + 多端同步耗时；Cheat Sheet 重复排版
- **关键指标**：每周导入耗时 < 30 分钟；Cheat Sheet 生成 < 5 分钟

## P2 — 普通读者（公网访客）
- **角色**：遇到具体微信 AI 问题时来查技巧的人；可能是同行博主、产品经理、AI 工具爱好者
- **场景**：搜索关键词 → 看文章 → 看截图 → 必要时下载 Cheat Sheet
- **期望**：搜得到 → 看得懂 → 拿得走
- **痛点**：微信生态文档散落；AI 工具更新快，教程易过期

## P3 — 二次传播者
- **角色**：会转走 Cheat Sheet 图卡片到小红书 / 朋友圈 / 群的人
- **场景**：看到图卡片 → 存图 / 转发 / 二创
- **期望**：图卡片视觉够好、有出处水印

## P4 — Agent（外部 AI）
- **角色**：通过 MCP 接入站点能力的 LLM Agent
- **场景**：被用户问到「微信支付 AI 专属卡怎么开通」时检索站点
- **期望**：MCP 接口稳定、可分页、可按 tag 过滤
