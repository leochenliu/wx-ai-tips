# User Journeys — 微信 AI 使用技巧整理站

> Stage 01 交付物

## J1 — 作者：导入一篇新文章
1. 在飞书知识库/多维表格写好一篇「微信 AI 技巧 + 截图」
2. 触发导入（CLI 或 Web 后台按钮）
3. 系统拉取 → 解析 → 入库到 CloudBase Postgres + 截图存 CloudBase 存储
4. 自动建议 tag（基于关键词或飞书原标签）→ 作者确认/调整
5. 文章公网可见，搜索引擎可索引

## J2 — 读者：搜索一个具体问题
1. 浏览器访问 `https://xxx.pages.dev`
2. 顶栏输入「微信支付 AI 专属卡」
3. 看到全文搜索结果列表（标题 + 摘要 + tag）
4. 点进文章 → 看正文 + 截图
5. 点「生成 Cheat Sheet」→ 选 PDF 或 PNG → 下载

## J3 — 二次传播：拿一张图卡片
1. 读者在文章页点「图卡片分享」
2. 后端用 puppeteer 渲染文章 → 输出 1080×1440 PNG（含站点水印）
3. 下载到本地 → 转发小红书 / 朋友圈

## J4 — Agent：通过 MCP 检索
1. 外部 Agent 调 `mcp.search({q: "微信支付 AI 专属卡 开通"})`
2. MCP 服务查 Postgres + FTS → 返回 Top N 摘要 + URL
3. Agent 据此回答用户

## J5 — 作者：批量重建 tag 索引
1. 文章变多后，某 tag 过时 / 太碎
2. 作者打开「Tag 管理」页 → 看 tag 频率云图
3. 选择「合并 X、Y、Z 为 Z'」或「重命名 W → W'」
4. 系统重建索引（一次性 SQL 事务）→ 触发增量 web 缓存失效
